# Documentation

Start with the [English README](../README.md) or [Simplified Chinese README](../README.zh-CN.md). The English README is the default repository entry point. Detailed installation and contributor guides are maintained in English.

PointDOM works with any coding agent client that supports local stdio MCP and can edit the linked project. No particular agent CLI is required for MCP. The named CLI integrations are optional ways to execute tasks automatically.
