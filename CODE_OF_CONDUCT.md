# Code of Conduct

PointDOM welcomes contributors with different backgrounds and experience levels. Be respectful, discuss code and behavior concretely, and assume good intent while remaining open to correction.

Harassment, discrimination, threats, personal attacks, sharing private information without consent, and deliberate disruption are unacceptable in issues, pull requests and other project spaces.

Maintainers may remove inappropriate content, lock discussions, or restrict participation. Decisions should be proportionate and consistent. Report concerns privately through an available maintainer contact; if none is available, ask for one without posting personal details publicly. Maintainers must also follow these rules.
