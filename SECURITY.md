# Security

Security fixes target the latest release. Older versions are not maintained separately.

Do not post pairing codes, model API keys, browser profiles, private project code or real task content in public issues. Use GitHub's [private vulnerability report](https://github.com/itscyrus-dev/PointDOM/security/advisories/new) if it is enabled. If private reporting is unavailable, open a public issue requesting a private contact method without disclosing vulnerability details. Maintainers must enable private reporting in repository settings before advertising it as available.

Include the affected version, platform, reproduction steps using a disposable project, and the impact. Relevant boundaries include loopback/Host checks, extension-origin pairing, local-only project registration, untrusted DOM input, project isolation and permission handling. Do not test against another user's environment or disclose active credentials.
